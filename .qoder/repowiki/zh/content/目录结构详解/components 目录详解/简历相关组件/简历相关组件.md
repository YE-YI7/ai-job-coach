## 简介
本项目中的简历功能组件为用户提供了一套完整的简历上传、解析、预览和优化建议展示的交互流程。这些组件协同工作，支持PDF和DOCX格式的简历文件处理，并通过与后端API的通信实现文件存储、内容提取和数据分析。系统设计注重用户体验，提供了拖拽上传、实时预览、错误提示和状态反馈等特性。

## 核心组件分析

### ResumePreview 组件
`ResumePreview` 组件用于渲染简历文件的预览界面，支持显示文件名、文件URL以及解析后的文本内容。该组件根据文件扩展名动态展示不同的图标（PDF显示红色文档图标，其他格式显示蓝色图标），并提供下载和删除操作按钮。当解析文本存在时，会在内容区域展示“解析后的简历内容”；若尚未解析或解析失败，则显示文件上传状态提示。

**组件特性**：
- 支持 PDF 和 Word (.docx/.doc) 格式文件的图标识别
- 显示文件名和基本元信息
- 提供下载和删除功能回调接口
- 展示解析后的纯文本内容或空状态提示

**Section sources**
- [ResumePreview.tsx](file://components/resume/ResumePreview.tsx#L1-L92)

### ResumeUploadBox 组件
`ResumeUploadBox` 实现了基础的文件上传交互功能，支持点击选择文件的方式上传简历。用户点击上传区域后可触发文件选择对话框，选择支持的文件类型（PDF、DOC、DOCX）。该组件通过 `onSelect` 回调将选中的文件对象传递给父组件进行后续处理。

**交互逻辑**：
- 使用隐藏的 `<input type="file">` 元素触发文件选择
- 通过 `useCallback` 优化事件处理函数性能
- 上传后重置 input 值以允许重复选择同一文件

**Section sources**
- [ResumeUploadBox.tsx](file://components/resume/ResumeUploadBox.tsx#L1-L56)

### ResumeEmptyUpload 组件
`ResumeEmptyUpload` 是一个增强版的空状态上传组件，不仅支持点击上传，还实现了拖拽上传功能。用户可以将简历文件拖入指定区域完成上传操作。该组件在视觉上提供了更明确的操作指引，提示用户“点击或拖拽文件到此处”，提升了交互友好性。

**核心功能**：
- 支持鼠标点击选择文件
- 支持拖拽文件上传（`dragover` 和 `drop` 事件处理）
- 使用 `useRef` 管理文件输入元素引用
- 通过 `onFileSelect` 回调向外传递文件对象

## 组件职责划分与布局场景

### ResumeChatPanel 与 ResumeCenterPanel 的职责划分
这两个组件分别代表了两种不同的布局场景下的功能模块：

#### ResumeChatPanel
位于聊天界面一侧，主要职责是提供一个与AI助手对话的交互面板。用户可以在其中输入问题，获取关于简历优化的建议。该组件维护自己的消息列表状态，支持发送消息、接收AI回复，并展示加载动画。

**功能特点**：
- 支持键盘回车发送消息（Shift+Enter换行）
- 自动滚动到底部显示最新消息
- 显示AI回复时的加载状态
- 消息气泡区分用户与AI

**Section sources**
- [ResumeChatPanel.tsx](file://components/resume/ResumeChatPanel.tsx#L1-L137)

#### ResumeCenterPanel
作为中心内容区域的主控组件，`ResumeCenterPanel` 负责管理简历上传、解析和预览的完整生命周期。它根据内部状态（idle、uploading、parsing、ready）切换显示不同的子组件：
- `idle`：显示 `ResumeEmptyUpload`，等待用户上传
- `uploading` / `parsing`：显示加载动画
- `ready`：显示 `ResumePreview`，展示已解析的简历内容

该组件还集成了对 `/api/resume/upload` 和 `/api/resume/parse` 的调用，实现了文件上传与解析的串联逻辑，并处理删除和下载操作。

**状态管理**：
- 使用 `useState` 管理当前状态、简历数据和错误信息
- 封装完整的上传→解析→展示流程
- 提供错误弹窗提示机制

## 与后端API的协同工作流程

### 文件上传流程（/api/resume/upload）
当用户选择文件后，`ResumeCenterPanel` 会通过 `fetch` 请求调用 `/api/resume/upload` 接口。该接口执行以下步骤：
1. 认证检查：验证用户登录状态
2. 文件解析：使用 `formidable` 解析 multipart/form-data
3. 格式验证：仅允许 .pdf、.doc、.docx 文件
4. 存储上传：将文件上传至 Supabase Storage
5. 数据库记录：在 `user_resumes` 表中插入新记录，包含 resume_id 和 public URL
6. 返回结果：返回 resume_id 和 file_url 供前端使用

**Section sources**
- [upload/route.ts](file://app/api/resume/upload/route.ts#L1-L140)

### 简历解析流程（/api/parse-resume）
上传完成后，前端自动调用 `/api/resume/parse` 接口进行内容解析：
1. 用户身份验证
2. 根据 resume_id 查询数据库获取文件 URL
3. 从 Supabase Storage 下载文件内容
4. 按文件类型调用相应解析器：
   - PDF：使用 `pdf-parse` 提取文本
   - DOCX：使用 `mammoth` 提取原始文本
   - DOC：暂不支持，返回错误提示
5. 将解析结果存入数据库 `parsed_text` 字段
6. 返回解析后的文本内容

**Section sources**
- [parse/route.ts](file://app/api/resume/parse/route.ts#L1-L228)

### 删除简历功能（/api/resume/delete/[resume_id]）
通过 `ResumeCenterPanel` 中的删除按钮调用 DELETE 方法请求 `/api/resume/delete/{resume_id}` 接口，实现简历删除功能。该接口应验证用户权限并从数据库和存储中移除相关数据。

## 组件集成示例：简历优化阶段
在简历优化阶段，各组件协同工作的典型流程如下：

1. **初始状态**：`ResumeCenterPanel` 显示 `ResumeEmptyUpload`，提示用户上传简历。
2. **上传触发**：用户点击或拖拽文件，触发 `onFileSelect` 回调。
3. **上传处理**：
   - `ResumeCenterPanel` 将状态设为 `uploading`
   - 调用 `/api/resume/upload` 上传文件
   - 获取 `resume_id` 和 `file_url`
4. **自动解析**：
   - 状态切换为 `parsing`
   - 调用 `/api/resume/parse` 接口
   - 获取解析后的文本内容
5. **预览展示**：
   - 状态设为 `ready`
   - 渲染 `ResumePreview` 组件
   - 显示文件名、图标、下载/删除按钮及解析内容
6. **AI交互优化**：
   - 用户在 `ResumeChatPanel` 中提问
   - AI 分析 `parsedText` 并给出优化建议
   - 建议内容同步至 `Whiteboard` 白板组件
7. **编辑建议展示**：
   - 白板组件展示优化建议卡片
   - 用户可点击进入编辑器进一步修改

此流程实现了从文件上传到内容展示再到智能优化的闭环体验。

## 白板组件中的简历解析区域

### Whiteboard 组件中的简历功能
`Whiteboard` 组件在 `resume_optimization` 阶段集成了简历解析与展示功能，其结构如下：

```mermaid
flowchart TD
A[Whiteboard] --> B{currentStage === "resume_optimization"}
B --> |是| C[显示简历解析区域]
C --> D{isResumeProcessing}
D --> |是| E[显示加载动画]
D --> |否| F{resumeData 存在}
F --> |否| G[显示上传入口]
F --> |是| H[显示预览与操作栏]
H --> I[展开/收起预览]
H --> J[下载/删除按钮]
H --> K[展示简历摘要与章节内容]
```

**关键属性**：
- `resumeData`：传递简历元数据和解析内容
- `isResumeProcessing`：控制加载状态显示
- `onFileUpload`：绑定文件选择事件
- `onDeleteResume` / `onDownloadResume`：处理操作请求
- `onTogglePreview`：控制预览区域展开状态

该区域不仅支持简历上传与预览，还能展示AI生成的优化建议（通过 `resumeInsights` 字段），形成“上传→解析→建议→编辑”的完整工作流。
