## 修复边界

1. 编辑目标明确为内容优化；逐条价值检查区分 correction / content。首轮只有纠错时，回原编辑一次；最终仍只有纠错，保存状态必须是部分交付 `resume_correction_only`，不冒充内容优化完成。不减少独立整稿检查，不增加 Agent，不绕过事实/格式/CAS/收费门禁。
2. 有效本人原话尚不能定位到既有经历时，正常讨论并只问所属经历；不新增猜测的公司/岗位，也不把这种情形当作发送失败。伪造消息 ID、非原话引用及非法字段仍拒绝。
3. 未验证的 revise 承诺不提前流出；普通讨论保留逐步显示、安全 Markdown 和聊天气泡。
4. 在模型前发出已持久化的消息回执；导师决策保存后，先发出已保存回复回执，再运行编辑。后续编辑或最终流失败，不改变已完成的对话，不把已收消息放回输入框。未确认保存的预显讨论明确标识，不宣称已保存。
5. 草稿与组件以 task 而非当前补问为键；兼容迁移旧补问草稿。切换问题、编辑状态变化或晚到失败不覆盖下一条草稿。
