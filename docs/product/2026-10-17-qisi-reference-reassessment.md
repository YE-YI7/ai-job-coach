## 真正值得用的设计关系

### 1. 先建立主次，不能把“少方块”执行成“所有东西一律扁平”

首页的大标题与紧凑侧栏是刻意不同的尺度。作品画面承担视觉信息，导航不争抢注意力。画廊中的 Agent 浮窗案例本身仍有容器，其作用是表达“当前在操作哪一层”。

**益职落点**：简历是主要工作对象，导师是伴随操作，低频设置再低一级。文档、编辑控件、对话不能仅靠三种接近的灰色并排，最后同样重。保留左栏，不意味着中间继续采用面板拼接。首屏要同时看到足够的正文和清晰下一步，不能为了一个漂亮的大标题把简历推下去。

### 2. 质感来自一套几何与光影关系，不是加一个阴影属性

公开图片 [弹窗设计](https://static.qisimiaoxiang.com.cn/works-test/work_1279_01.png) 有表面、边缘与投影的层次；[Unlock Port](https://static.qisimiaoxiang.com.cn/works-test/work_222.png) 用顶部亮边和底部投影表现可按压感。后者是材质参考，不意味着简历所有按钮都要拟物。

作者文章把两项容易忽略的工艺讲得很具体：内外嵌套圆角需要与间距对应，图标需要按视觉重心对齐；细阴影也可以承担边界的作用，而不是总用实线。不能把“同尺寸图标、同一个圆角”当成已经精致。

**益职落点**：纸张保持纸张的几何；采纳浮层、更多菜单、输入区域分别有明确层级，避免整页每个容器都是一个圆角和一条灰边。重点检查导出按钮、输入区发送按钮、浮层内动作与容器转角的关系；不把参考的玻璃效果强加到正文上。

### 3. 操作的前后状态要连贯，不是弹出一个独立盒子就结束

[更多展开动效](https://static.qisimiaoxiang.com.cn/works-test/work_968.mp4) 在同一个紧凑区域内从书名信息切换为操作，入口和结果保持位置联系。它不是凭空出现另一块卡片。六帧记录见 [motion-968.png](evidence/2026-10-17-qisi-reassessment/motion-968.png)。

**益职落点**：阅读 → 选中一段 → 采纳/保留 → 回到正文，是同一对象的连续状态。批注工具就近出现，处理完适度退场；不能采纳后视线还停在一组失去作用的按钮上。撤销应继续可达。不要让所有控件都弹跳，也不要用动画延迟操作。

### 4. 成功反馈就发生在操作的位置

[复制过渡](https://static.qisimiaoxiang.com.cn/works-test/work_1003.mp4) 把 Copy 转成 Copied，图标和文字的状态一起变更。六帧记录见 [motion-1003.png](evidence/2026-10-17-qisi-reassessment/motion-1003.png)。作者另外解释了可中断动效：用户改变意图时应立即响应，不能等一段演出播完。

**益职落点**：处理建议后就在该处给简短反馈；工具栏稳定表达“正在保存 / 已保存 / 保存失败，可重试”。网络成功回执前不能提前显示“已保存”。按钮宽度、状态文字和焦点不应让纸面跳位；失败保留内容。动画只解释状态，不伪装模型或云端进度。

### 5. Agent 的进度需要有结果和归宿

[Subagents 面板](https://static.qisimiaoxiang.com.cn/works-test/work_1272.mp4) 将执行中和完成项分组，子任务逐项改变状态，完成任务从活动区归档，而不是一直占着同样的位置。六帧记录见 [motion-1272.png](evidence/2026-10-17-qisi-reassessment/motion-1272.png)。

**益职落点**：展示真实的“读材料 / 起草 / 检查”当前阶段和可用结果，结束后让成稿接管注意力。若没有真实后端事件，不制造细分步骤、精确百分比或倒计时。导师缺材料时仍一次问一个；面向作者的质量 trace 不变成给用户的暗评分，也不把内部日志全摊在简历旁边。

### 6. 品牌表现和工作状态不能共用一种强度

[AI 输入组件](https://static.qisimiaoxiang.com.cn/works-test/work_1260_01.png) 的氛围来自整体背景与紧凑输入的反差；[Replay 版式](https://static.qisimiaoxiang.com.cn/works-test/work_1278_01.png) 的图像、字体和边缘装饰共同构成风格。孤立复制一个渐变或粗标题无法得到相同效果。

**益职落点**：公开介绍页、首次进入、上传空状态可以更有视觉表现力；开始读简历和编辑后，应让这些东西退下去。不能用“工作台要克制”推导“全站只能米灰绿”；也不能为了有记忆点把纹理、玻璃和渐变全部叠进正文。

## 下一轮只设计简历板块的四个连续状态

- **阅读态**：保留左侧栏和真实纸面，明确文档与导师的主次；主要动作易找，低频工具不常驻成墙。
- **选中态**：工具与对应内容保持空间联系；浮层轮廓、转角和投影有完整关系；键盘与触屏不能依赖 hover。
- **处理态**：采纳、保留、手改有即时反馈和撤销；连续操作可以打断当前动效，不抢焦点、不跳版。
- **补问与保存态**：一次一个问题，已有事实先改；回答保留、真实保存回执、失败重试明确，结束后回到成稿。

先把这四态放在同一套视觉目标里评判，再做代码实现与真实链路复验。本轮不再次用检测通过、构建成功或线上健康代替视觉认可。
