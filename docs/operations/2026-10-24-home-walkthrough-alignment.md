## 原因与修改

用户截图来自正式 `yizhioffer.com`。本轮在正式公共首页实际向下滚动并返回题目，复现了热区落在空白、面试批注混入岗位/简历内容、导航覆盖窗口标题。只操作虚构首页演示，未进入真人工作区。

1. **热区沿用旧图坐标**：当前 `interview-prep.webp` 为 1556×1382，“练一道题”在 x≈0–225、y≈403–490；旧 CSS 仍 left 5.2%、top35.2%、宽16.6%、高8%。改成对应本图的 0 / 29.16% / 14.46% / 6.3%，截图容器明确使用该图宽高比；手机自动定位跟随同一目标中心。
2. **批注列表无场景隔离**：setTab 只把旧节点变淡，导致新场景展示旧内容，回滚还会移除未决选择的状态。新增小型 `createWalkthroughNotes`，按场景保留真实 DOM 节点和滚动位置，切换时恢复当前列表，不清除选择监听；未显示的正文 pane 设 inert/aria-hidden，离开面试暂停并关闭文字回放。
3. **固定导航未让位**：导航顶16px/高58px，原大窗口在中等高度视口从45px开始，标题被盖。sticky舞台预留顶部90px和底部18px，窗口缩到视口减126px；手机移除重复112px顶边距，窗口减214px，为章节行与导航留空间。

修改只涉及首页内容、CSS、演示交互和回归测试；未修改模型、登录、收费、保存/打印或数据库逻辑。晨光v5视觉、现有材料入口和原型来源 SHA 保留。
