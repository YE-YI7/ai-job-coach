## 问题与范围

上一版只在“新建实测”安装完整观察作用域；日常工作区只有 metadata，普通阶段又被映射为 input/output=null。页面首先打开空阶段，使已有的真实模型调用也不易发现。历史正文没有保存，不能回填或用旧作答拼造。

本次补齐真实 `/api/coach/resume-draft` 观察：仅 `EVAL_ADMIN_USER_IDS` 明确授权的账号；其他普通用户与仅有通用管理员邮箱的账号不会自动采集正文。采集对象包括当前简历/JD、上下文编译、实际纳入的知识正文和 ID、每次模型可见消息与原始响应、事实校验/独立质检的中间产物、实际接口结果与异常。不采集隐藏思维链，不为 Trace 增加改稿或自评模型调用。

完整内容只写服务端专用 `coach_eval_runs`。原有 `product_events` 仍只有 metadata，测试覆盖正文不泄露到通用事件。采集数据库失败不阻断正常业务响应；显式验收编号需先写入，重复编号不重复执行模型。已有显式实测作用域不再嵌套生成第二条记录。并发通过 AsyncLocalStorage 隔离。

UI 默认打开有 I/O 的实际调用，失败优先；历史记录标为“历史摘要”，空阶段解释仅有状态/时间，不伪装成完整回放。实际捕获的阶段替换同一 metadata 打点而不重复显示。保留现有页面视觉与工作区侧栏。
