# Qoder / Grok 交付联合验收

2026-10-19（本地）。当前是发布候选验收记录，不能将未完成项当作已上线。

## 接收与修复

Qoder 的交付仅接收 Eval 四文件：`public/eval-lab/index.html`、`app.mjs`、`styles.css`、`scripts/eval-lab.test.mjs`。共享树中的导师输入区、ModelPicker 删除、CockpitApp 等其他在途改动全部排除。左侧业务导航与用户原稿不改。

本次审查发现并修复：

- 反馈 POST 晚返回会清空另一条运行的输入，或错误地给新记录标记成功；现在以运行与页面代次隔离。
- 失败后切记录、刷新会丢草稿，且修改内容后复用旧幂等 ID 会冲突；现在按运行保存草稿，结果不明时冻结原请求正文与 UUID，先确认原提交，明确拒绝后才允许重填。
- 提交前发出的 GET 可能覆盖刚确认的反馈列表；失效旧读取。后台回执需精确匹配反馈、运行、修改与 scope。
- 从实验打开较早运行后刷新会跳回最新二十条，造成反馈像丢失；现在按已选 ID 单条恢复真实证据，不把占位元数据当正文。恢复后更新左栏名称与状态。
- 实验列表缺内部 Trace 关联，外部盲评没有展示/持久化；现在返回真实 `legacy_trace_id`，三份盲评按答案键逐条关联运行，CAS 更新私有批次摘要并回读，不更改模型原始输入输出。
- 新反馈状态色复用 Eval 已有语义变量，新触摸操作最小高度 44px。历史颜色/圆角 advisory 不扩大改动。
