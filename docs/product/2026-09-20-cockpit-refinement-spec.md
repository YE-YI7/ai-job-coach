# 作战台精简与诚实化改造 spec（2026-09-20 实测反馈）

来源：用户 2026-09-20 全流程实测后的逐屏反馈。验收标准统一为：**界面没有废话、状态不说谎、用户的选择永远生效、AI 只夸海口不越权**。

## 0. 真 Bug（最高优先级）

| # | 现象 | 根因方向 | 验收 |
|---|------|----------|------|
| B1 | 进入桌面被「DeepSeek Chat 当前不可用，不替换模型」拦住 | 模型可用性判断把用户显式选择也拦死 | 用户选了哪个模型就用哪个；确实不可用时给出可操作解释，不阻塞主界面 |
| B2 | 切到其他岗位再回来，模型被重置为「自动优选」 | 选择未按用户持久化 | 模型选择跨岗位、跨刷新保持 |
| B3 | 已有面试复盘，右边辅导对话问「我一面怎么样」说不知道 | 复盘记录未接入对话上下文 | 辅导对话能引用当前岗位已保存的复盘/练习记录并说明来源 |
| B4 | 简历审阅中「无需修改」的块也要求用户确认 | 确认列表未按实际 diff 过滤 | 只有真实改动的块需要确认；无改动块直接展示为未改 |
| B5 | AI 改写做同义换词（拆成→拆解为） | prompt 无「无意义改动不提交」约束 | 改写只保留有信息量的修改；质量不足时宁可原样保留 |

## 1. 简历工作台

- 页面从上到下只保留：**进度 → 上传入口 → 一键生成 AI 简历 → 简短真实评价 → 渲染后的完整简历**。删除其余堆料。
- 评价区只说「还缺什么」：即使 AI 把简历改好了，若硬实力（经历/技能）仍不支撑目标岗位，如实推荐去补；若没有此类短板，**整块不显示**，不放鼓励性废话。
- 简历按块渲染（教育经历、每一段项目、实习经历各一块）：
  - 每块不同颜色边框 + 浅色背景；
  - 本次改动文字用另一颜色笔迹标出，一目了然；
  - 鼠标悬停块上方弹气泡：这一块**为什么这么改**；
  - 块可拖拽调整顺序；点击块进入手动编辑局部内容。
- 版式模板选择：显示三种版式的**可视化缩略预览**（迷你排版图），不再是三个纯文字按钮。

## 2. 模拟面试（中间）与快速练习（右侧）

- 中间 = 完整模拟面试：选轮次（排版重做，现有 RoundPicker 不美观）、**题目数量由用户选**（3 起步，可选 3/5/8）、去掉「业务面试官/用人经理/证据审校」三个装饰席位。
- 出题分类（业务面/技术面/项目深挖/总监面/HR面）对照真实面试实践校验后修正。
- 右侧对话 = 轻量「快速练一题」：像跟老师聊天，一样耗额度但不做系统性七维分析。
- 页面元素只保留：当前题、输入、反馈、下一步。删掉一切流程宣讲长文案。

## 3. 面试复盘

- 排版重做：记录输入区紧凑化，报告区结构化。
- 输入除粘贴逐字稿外，支持**上传录音文件（MP3 等）**（存 Supabase，转写走已有链路；无转写能力时如实告知并保留文件）。
- AI 复盘不再一次性吐结论：先保存材料 → 在右侧对话中**一步步引导用户自己说**：这次面得好不好 → 哪里不好 → 哪里有提升空间 → 下一面怎么应对 → 对该岗位接下来怎么打。AI 只追问与点评，不代写答案。

## 4. 投递跟踪

- 删除中间页的投递跟踪长文案与独立阶段页。
- 投递状态只体现在**左栏每个岗位行的状态词**（如「已投递」「面试中」）。
- 状态变更由导师在对话中**意图识别**（用户说「我投了」→ 确认后更新阶段），不做单独录入界面。

## 5. 对话窗与全局 UI

- 所有下拉/选择框不用原生样式，统一自绘。
- 输入框去掉「AI 味」：聚焦不再出现紫粉色方框；圆角、间距、反光等细节统一（克制的液态玻璃质感）。
- 模型选择：显示各家**官方 logo**（DeepSeek/Kimi/GLM 等下载到 public/），仅「名字 + 速率」，不写介绍文案。
- 语音输入：收成输入框右下角一个波形小图标，无文字；可用图标处一律不写字。
- 「学习笔记/添加关键收获」：位置不对且无处回看——从当前页面移除，收获沉淀走对话上下文已有链路。
- 右侧辅导对话与中间页面**不再隔离**：对话上下文实时携带「当前页面 + 用户最近操作/修改」，导师可主动发问。
- 左栏岗位列表：支持删除、拖拽排序、置顶。

## 6. 不动的东西

- 上一轮修掉的状态诚实化逻辑不回退。
- 数据层 schema 不迁移；本轮以 UI/上下文/提示词修复为主，能本地闭环的不上后端。

## 测试

- jest + tsc + eslint 全绿；
- `npm run dev` 浏览器实测：简历台（含空简历）、面试台、复盘、模型切换与持久化、左栏操作；
- 无法真实验证的项（如录音转写质量）在报告中如实标注。
