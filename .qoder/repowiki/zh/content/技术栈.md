## 项目结构

ai-job-coach项目采用Next.js App Router架构，核心目录包括：
- `app/`：基于App Router的页面和API路由
- `components/`：可复用的UI组件
- `lib/`：业务逻辑、工具函数和状态管理
- `store/`：全局状态管理实现
- `supabase/`：数据库模式定义

项目通过模块化设计分离关注点，前端组件与后端逻辑清晰分离，便于维护和扩展。

## 前端技术栈

### Next.js 16 + React 18

项目采用Next.js 16作为核心框架，充分利用其现代化特性。`package.json`显示依赖`next: "16.0.7"`和`react: "18.3.1"`，确保使用最新的React特性。

Next.js的App Router架构提供了基于文件系统的路由，如`app/chat/interview/[round]/page.tsx`等页面路由，以及`app/api/`目录下的API路由。这种架构支持服务端渲染(SSR)和静态生成，提升首屏加载性能和SEO。

### 样式方案：Tailwind CSS

项目使用Tailwind CSS作为主要样式方案，通过`postcss.config.mjs`配置集成：

```javascript
const config = {
  plugins: {

};
```

`app/globals.css`中通过`@import "tailwindcss";`引入Tailwind，同时定义了自定义CSS变量和动画。项目还实现了暗色模式支持，通过`:root`和`@media (prefers-color-scheme: dark)`切换主题。

Tailwind的实用优先方法论与项目结合紧密，如`chat-bubble-ai`和`chat-bubble-user`等组件类名直接体现了样式意图，提高了开发效率和代码可读性。

### 动画库：Framer Motion

### 状态管理：React Context

值得注意的是，项目并未使用Zustand进行状态管理，而是采用原生React Context API。`store/interviewStore.tsx`实现了模拟面试的全局状态管理：

```typescript
const InterviewContext = createContext<InterviewStore | null>(null);

export function InterviewProvider({ children }: { children: ReactNode }) {
  // 状态定义和方法实现
  return <InterviewContext.Provider value={value}>{children}</InterviewContext.Provider>;
}
```

`app/providers.tsx`中使用该Provider包装应用：

```typescript
export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <InterviewProvider>
      {children}
    </InterviewProvider>
  );
}
```

这种设计模式避免了额外的依赖，同时提供了良好的类型安全和开发体验。

```typescript
export async function callLLM(
  messages: Message[],
  options?: {
    provider?: "deepseek" | "openai";
  }
): Promise<string> {
  const provider = options?.provider || "deepseek";
  const apiKey = provider === "deepseek" 
    ? process.env.DEEPSEEK_API_KEY 
    : process.env.OPENAI_API_KEY;
  
  const client = new OpenAI({
    apiKey,
    baseURL: provider === "deepseek" 
      ? "https://api.deepseek.com" 
      : undefined,
  });
  // ...
}
```

此设计提供了灵活性，允许在不同LLM提供商之间切换，同时通过统一的API简化了调用逻辑。

## 性能优化与安全

### 服务端渲染优势

项目充分利用Next.js的服务端渲染能力，特别是在`app/page.tsx`等页面中。SSR的优势包括：
- 更快的首屏加载时间
- 更好的SEO表现
- 改善的用户体验，特别是对于内容丰富的页面

### 安全配置

项目实施了严格的内容安全策略(CSP)，在`next.config.ts`和`app/layout.tsx`中双重配置：

```typescript
headers: [
  {
    key: "Content-Security-Policy",
    value: [
      "default-src 'self' https:",
      "script-src 'self' 'unsafe-inline' 'unsafe-eval' https://cdnjs.cloudflare.com https://cdn.jsdelivr.net",
      // ...
    ].join("; "),
  },
]
```

这种防御性配置有助于防止XSS等常见Web攻击，保护用户数据安全。
