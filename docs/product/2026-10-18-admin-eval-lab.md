# 管理员 Eval Lab

## 交付范围

正式入口 `/admin/evals`，复用益职现有登录。`ADMIN_EMAILS` 或精确的 `EVAL_ADMIN_USER_IDS` 授权；后者只影响 Eval，不扩张邀请、支付等权限。匿名 API 401，非管理员 403。浏览器同域访问，凭据不传到独立 Sites。

一次运行包含输入、阶段 Trace、实际知识 ID、逐次模型可见输入/输出、结果、LLM 自评及原因。程序规则分、自评分、人工判定分开。旧版 Trace 缺少正文时保持“未采集”，不根据旧作答补齐，也不把最终成功倒推成每阶段成功。打点间隔来自累计时间相减，实际模型调用耗时另记；不采集隐藏思维链。

“新建实测”使用管理员明确提交的样本、可选 JD、计费确认和可选额外自评。沿用真实改稿入口，不带旧岗位或旧任务 ID。独立 `coach_eval_runs` 表启用 RLS，普通 authenticated/anon 没有表授权，服务端管理员检查后访问。迁移 `20261018033656_admin_eval_runs.sql` 已执行并通过 information_schema 核验，schema 快照同步。没有自动清理或默认采集普通用户正文。

每个请求先原子插入 UUID 再调用模型。相同 UUID 重放返回既有记录，不会重复执行。模型 I/O 每次调用前后写入，网络中断后可用原编号核对/重试；数据库初次写入失败不调用模型。并发观察通过 AsyncLocalStorage 隔离。正常改稿无观察作用域时仍使用原始调用参数，不记录正文。

历史记录默认只读载入。导入 JSON 仅当前标签页内存；人工判断需要显式保存到本机，不声称已同步云端。导出包包含本次输入/输出，需自行妥善保管。演示全为显式虚构样本，与正式记录分开。

## 验证

- 新增权限、观察隔离、失败、去重、跨站与旧材料隔离单测通过；生产 schema 契约通过。
- UI 8 项 Node 测试通过：旧 Trace 不造自评、非法/过大/循环输入、导出回读、凭据屏蔽和独立评分口径。
- TypeScript、目标 ESLint、diff check 通过。手动 Impeccable detect 一次，零发现；自动钩子保持关闭。
- 全量：2307 通过、9 跳过、4 失败。四项均为修前已存在的 Manus/Greenhouse/Lever/Ashby 岗位链接导入预期 200 实际 503，不在本次改动范围，不声称全绿。
- Chrome 本地演示与真实旧元数据导入：五标签、切阶段、人工备注切页保留/显式保存、非法导入不损坏当前记录、旧规则100不冒充自评。桌面1440×1000、手机390×844无横向溢出。

正式发布、真实模型、刷新及旧作答复核待下文补记；上述本地检查不是正式验收。

## 限制

这是观察/诊断工作台，不是已经校准的离线 Eval 数据集平台，不以一个自评分证明改稿质量已修好。没有后台自动重跑、批量付费、旧记录回填、普通用户正文抓取或其他管理员权限扩张。先前注册的私有 Sites 壳未发布，不作为正式入口。
