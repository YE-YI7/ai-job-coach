# Harness 正文绑定与检索止损修复 · 2026-10-09

## 本次采用的原则

阅读用户提供的 `/tmp/wechat-extract/sources/` 四篇正文：淘宝数据分析助手实战、Agent 评测体系分享、淘宝直播 Harness-Aware Training、OpenViking 三篇论文解读。采用资料分层、内容失效、轨迹与最终状态一起验收、超预算停止等原则。评测体系分享为第三方评论，不视作美团官方规范；正文未含图片表格，不声称已核验图中细节。

不引入新训练流程、OpenViking 服务或大公司数据基础设施，不删除现有交互。

## 已修复

- 上下文指纹绑定实际纳入的事实、来源、可见性、产物正文和知识片段正文，同 ID、同版本、同长度的修改也会使旧上下文失效。编译器标记更新为 `context-content-bound-v3`，进入 Harness 配置指纹。
- 回放用材料类型与 ID 联合匹配，检测实际正文变化；没有进入预算的事实不再进入可引用清单，未纳入的历史摘要不返回。禁用事实仍保留禁用原因。
- 检索子 Agent 按实际返回正文核算 token，失败调用计入工具消耗；剩余时间耗尽时返回失败并停止后续扇出，传递取消信号。
- 招聘日期在未来或计算时间无效时标为待核实，不再误认为近 30 天在招。
