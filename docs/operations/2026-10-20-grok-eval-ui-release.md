- 连续同步打点的零毫秒显示“未单独计时”；保留原始数值和总耗时，不推算新耗时。

- 验收修复：不再按数组长度舍弃部分知识记录；保留阶段自身已有知识，不用运行总表覆盖。前端去重比较也保留采用状态与片段的差异。
