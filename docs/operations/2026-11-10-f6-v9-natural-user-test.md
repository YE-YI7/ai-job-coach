接续Eval实际payload只有`resume / jd / currentChanges / question / savedAnswers / mentorGuidance / conversation / knowledge`等；没有独立的最新完整候选正文。`resume`是原稿，`currentChanges`包含before/after，最新after已经没有“带1名”；但mentorGuidance仍引述这个已修好的旧错。AI必须自行拼接当前稿、判断引用是哪版，又把原稿句子挂到用户消息ID。这是上下文版本与来源交接缺口，不是缺了搜索结果。它对这次错误的影响需受控试验证明，不能单凭字段缺失就说修好它一定全过。
