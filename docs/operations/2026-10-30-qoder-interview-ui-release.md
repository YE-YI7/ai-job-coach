## 实现及验收中修正

1. 把涉及的 `RoundSummary` 独立为 `InterviewRoundReview`，按结论、覆盖进度、数值、原话、点评、逐题回看和自我复盘分层。无真实总评时保留原来的未评分/重试流程，不补造总分。
2. 历史页只换日期、轮次/岗位、作答覆盖数和展开箭头的信息层级；已有云端读取、搜索、分页、选中记录和 URL 恢复逻辑不变。
3. 旧跳过标记不得计为真实回答；“跳过追问但保留原答”仍按真实回答计数。进度状态同时有文字，不只依赖颜色。
4. 首次手机实拍发现源样式的 container query 无容器，导致标题碎裂。增加结果页自己的 inline-size 容器后复验；390 宽标题正常，页面无横向溢出。
5. 新输入框保留白色书写面和向下柔影，不加彩色聚焦框/下划线；交互至少 44px；保留按钮键盘焦点和 reduced-motion。共享维度条样式显式合并，避免 CSS module 同名覆盖后条形失效。
6. 开发专用虚构夹具由服务端参数确定初始视图，避免 effect 同步 setState 和刷新闪回结果页。生产预览路由仍由原有 development 闸保护。
