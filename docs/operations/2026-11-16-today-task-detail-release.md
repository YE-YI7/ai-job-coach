## 实施

- `TodayWorkspace` 只提取任务渲染块，复用既有导航/延后/完成回调。
- `TodayTaskList` 将标题/说明/时长与动作分轨；主按钮保留细微压下和箭头前移，辅助命令始终可见，触控44px。
- 完成图标为无框的双勾，不使用 checkbox/aria-pressed；仍是原来的自报完成命令，没有新增反选功能。
- 任务移走后，反馈显示原任务标题并留在原序位，说明当前页面的本地结果。不把组件点击、绿色或本地回调等同云端保存；原保存失败提示和重试不改。
- 只对真实已有动作提供反馈，无人为 loading、额外请求、收费或模型调用。减少动态时禁用本次动画和位移。
