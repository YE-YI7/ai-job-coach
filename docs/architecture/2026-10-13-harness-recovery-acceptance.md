# Harness 恢复、并发与原文读取修复验收

日期：2026-10-13。对应审查 H-01/H-02/P0 与 H-03/H-04。

## 实现

- 恢复路径位于额度预扣之前：同 owner、requestId、原问题、会话、岗位和已保存模式一致时返回原 turn，不调模型、不重新收费。计费 header 与 body 编号统一，冲突在执行前拒绝。
- `coach_agent_requests` 持久化主键锁先于预扣和模型，所有计费来源共用；保存输入指纹、执行凭证和结果。重复并发只读状态；不会靠进程内 Map 或模型调用后的 turn 唯一约束防重。
- 进行中/结果未知重试保留原 requestId；明确失败才换新的 attempt。前端重试不被额度预检拦住，真正新生成仍由服务端检查额度。
- 最近窗口之外按同账号、同会话检索旧原话；相关旧笔记按内容召回，不只取最近三份。保留来源 turnId 与跨岗位参考标识，不把历史导师推断当用户事实。
- 长简历按问题选择完整原句和行号，逐句改写仍走严格原文链路。把已保存/本轮部分可见/预算未装入的材料清单告诉导师，不把“未读”说成“未上传”。
- 仅新增表/函数与请求处理；不更新或迁移历史 interview_answers。
