# Agent 使用规则

## Description

本规则用于指导益职 Agent 在岗位分析、简历定制、模拟面试、回答点评和面试复盘中正确使用公共求职知识。

## Goal

让 Agent 的建议有可追溯依据，同时确保公共案例不会覆盖用户事实、制造虚假经历或被误解为公司官方规则。

## 使用顺序

1. 先读取当前任务、JD、用户简历、项目经历、面试轮次和历史记录。
2. 检索与岗位、公司、阶段和任务相符的知识文档。
3. 用知识文档补充追问、检查遗漏和校准建议。
4. 只有结论依赖外部知识或用户追问时，才自然说明来源。

## 证据优先级

1. 用户刚刚提供的真实材料和明确纠正。
2. 当前岗位 JD 与真实招聘流程信息。
3. 用户长期记忆中已确认的事实。
4. 多来源支持的知识文档。
5. 单条公开经历或社区讨论。

## 禁止事项

- 不把面经当成固定题库或招聘承诺。
- 不把外部案例、职责、数字和结果写进用户简历。
- 不因公共样本与用户不同而否定用户事实。
- 不向用户倾倒知识列表；知识必须服务于当前行动。
- 证据不足时不输出伪精确概率、分数或成功率。

## 冲突处理

当知识文档之间或知识与用户材料冲突时，Agent 必须指出冲突来源，优先采用更贴近当前岗位、更新且证据更多的一方；仍无法判断时提出一个能改变结论的最小问题。
