# 09-16 审计后第一轮优化与验收

## 已改

- 对话中的明确简历/项目描述代写请求：一次结构化模型调用抽取来源，引文由服务端校验来源 ID、连续原文与分句边界。未经校验不流式展示。材料少时输出保守的「事实底稿」，不承诺已是润色完的投递版。未来练习单列，不算已完成经历。
- 这条路径不读取学习摘要/个人压缩摘要，避免导师推断回灌经历；来源与输入均有限额。普通辅导保持一次模型调用；只有原有超时降级可能再调用。
- 归档：模型选择原文，服务端核对说话人、来源和原文，显示自述/作答与待做练习，不再自由生成「已掌握」评价；无效 JSON 不归档、保留会话。原人工笔记不被覆盖。
- 快捷追问过滤替用户宣称「做过/完成/掌握」的按钮。
- 面试中栏主按钮直接打开单题并聚焦；没有重点题不再显示完成。右侧增加「练习 / 问导师」切换，组件不卸载，未提交答案保留；重复重点题默认折叠。减去中栏大面积深色块，扩大说明字号，保持暖白与橙色。
- trace 记录上下文就绪、首文本、生成完成的分段耗时，后续可据生产样本定位慢点。不宣称已完成生产 p95 优化。

## 验证

- 60 套件 / 505 项测试通过；改动文件 eslint、tsc、生产 build 通过。
- 本地 1440px / 390px 浏览器实际点击；主按钮出现文本框并聚焦；练习→导师→练习保留输入。390px document.scrollWidth=390。不是手机真机测试。
- 本地新版服务调用真实托管模型、临时独立账号使用现有数据库：两轮回复保存后回读 2 条，归档成功，新会话读到原项目及待做练习。测试账号清理完成，未动真实用户资料。
- 最终模型样本：普通辅导首字2.952秒/完成5.280秒；受约束底稿3.724秒整体返回，1256输入/288输出 token、1次模型调用；下一会话首字1.670秒/完成3.038秒。开发服务、网络和线上不同，不能作为前后生产提速比例或SLA。
- 最终底稿保留「课程作业、会议摘要原型、访谈3人、未上线」原文，没有增加演示/迭代/反馈结果；归档明确未认证，未写已掌握。

## 边界

这是保守可靠性的第一版，不是全面上线签收。自由聊天、下一步建议仍是模型生成，不能保证所有语义推断零错误。严格底稿目前由明确代写意图触发，不覆盖任意含糊追问；简历工作室另有其原有事实门禁，本轮未重写。

保留旧学习笔记，不擅自删除用户记录；历史错误摘要仍应复核。自动课程结束归档、主动用户级心跳、生产延迟分布、语音/PDF全链路、独立真人效果验收仍待继续。本轮不新增常驻沙箱或全用户轮询模型。
