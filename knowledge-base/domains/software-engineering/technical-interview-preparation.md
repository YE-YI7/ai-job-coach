# 软件工程技术面的分层准备

## 核心知识

当前小红书与字节公开样本表明，技术面不能只背算法题。项目深挖、工程机制、语言基础、数据结构与算法都可能出现，而且同公司不同团队、岗位和轮次差异明显。

## 准备层级

1. **项目深挖**：背景、个人责任、架构取舍、故障与验证结果。
2. **工程机制**：从用户项目与 JD 提取数据库、并发、网络、缓存、迁移等主题。
3. **语言与框架**：围绕用户真实技术栈追问原理和边界。
4. **数据结构与算法**：准备基础结构、复杂度和可运行代码表达。

## 公司样本的有限提示

- 小红书后端样本出现项目与开源经历、MySQL 数据迁移、语言熟悉度、链表和二叉搜索树。
- 字节面经合集提示同公司不同团队差异较大，应按岗位和轮次整理，多来源重复出现才提高优先级。

## Agent 使用方式

先从 JD 和简历生成知识域，再用公开样本补充追问。不得因为样本出现某题就把它描述为必考题；用户无法解释真实项目时，优先补项目证据，而不是继续扩充题目数量。
