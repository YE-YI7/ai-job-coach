# 简历区细节设计补齐 · 2026-10-17

## 这次具体改了什么

上一轮主要完成层级与减法，本轮按用户“小元素也要检查”的品味约束补控件与使用细节，保留现有左栏、文档样式和内容。没有新增卡片、常驻操作墙、字体或第三方图片。

- 主动作统一桌面 40px、手机 44px；历史/更多在触屏至少 44×44px，图标统一 1.65 线重，数字采用 tabular-nums。辅助说明从 11px 提至 12px。
- 修改标记由眼睛开闭表现状态，去掉重复对勾，保留明确的可访问名称和 aria-pressed。撤销/重做的悬停提示解释可用与不可用状态；提示左右锚定，避免被文档边缘裁切。禁用图标变淡，提示本身不受禁用透明度影响。
- 更多入口有展开反馈；菜单按实际高度决定上下位置，160ms 的小幅入场遵守 reduced-motion。打开后焦点进入首项，Escape 返回入口；改稿正在运行时不能触发替换简历。
- 实际复现点击普通纸面后采纳浮层仍悬留，已修为点击正文关闭、不抢焦点；Escape 路径仍还焦，浮层内部滚动沿用上一轮豁免。
- 编辑框聚焦采用同一强调色的光标和外框，清掉全局继承的输入框底部阴影。说明与输入相隔 14px，动作区相隔 20px；手机删除、取消、保存不再挤成两行。
- 导出确认增加清晰标题，按钮缩为“继续核对 / 同意并导出”。原有待确认计数、用户指定的同意提示、保留拒绝项和不自动采纳的语义未变。

## 实际验收与边界

独立 Google Chrome，虚构 studio 样例；1440px、390px、320px，另测 400px 短视口。未借用户 Cookie 或操作用户旧材料。

菜单首项焦点、Escape 返回、展开态、标记开关、普通纸面点击关闭均已实际走通。短视口菜单 top33.4 / bottom237，位于 400px 内；resize 后首个点击曾与尚未派发的关闭事件竞争，待尺寸稳定后验证通过，没有将该测试时序伪装成产品修复。reduced-motion 下菜单 animation-name 为 none。

手机导出确认两动作实际 80×44 / 95×44；取消保留建议，同意真实打开干净正文导出页，含姓名与测试用例文字，无修改标记或编辑按钮。手机编辑三按钮同 y588.98 且高44；说明不再贴输入框。390px 工具栏 clientWidth / scrollWidth 均346，320px 均276，无工具栏横向溢出。

两帧背景取样和前景合成：菜单说明 5.70:1、费用说明 5.25:1、标记文字 13.24:1。首次标记文字 1.88 是移除透明采样样式时恢复 color transition 的补间假报；常驻关闭过渡后复测，并未以该假报改动文字色。开发 HMR 曾沿用旧禁用透明度，整页重载确认最终按钮 opacity1，图标单独降透明度。没有把对比度数字当成审美通过。

全量229套2297项通过、5套9项 opt-in 跳过；类型与本轮TSX lint通过。手动 detect 一次、必要修复后一次复核：263发现 / 260 advisory，3 warning 均为未改历史面试边线和字体，逐diff无新增发现；不扩大修复或开启自动钩子。局部截图两轮检查，发现并修复手机编辑说明贴边、动作换行、提示边缘裁切。

本轮没有真实模型、云端保存或数据写入；不重报这些既有验收。未改 PDF 渲染器或纸面几何，实际导出页检查不称新生成了 PDF 文件；前轮一页 A4 文件证据保留在 [上一轮记录](2026-10-17-qisi-resume-ui-refactor.md)。旧作答未读取或修改。
