# 10-10 两份用户测试报告择优修复

依据：业务真源中文 outputs 下同日 resume-interview-coach-feature-test 与 updated-product-review。使用报告中的虚构履历做回归，不改真人材料或余额。

## 本轮完成

- 简历编辑来源只接作用域内上传原文和已确认事实，不将当前请求、历史提问、JD 或导师回答放进可引用来源。覆盖原报告“输出两条 bullet”路由，保持否定与参与/团队职责边界。已有事实优先使用，提示词禁止重新索要已有整份简历。
- 明确模拟面试进入独立 JSON 协议：首轮只有一题；回答后短反馈与一条追问；模式写入本轮 trace，下一轮沿用，主动要求教学可退出。格式错误返回 422，不保存伪完整反馈；不提前流出未核验的范文。保留原有反幻觉守卫。
- 用户回答在发往模型前保留到当前浏览器标签页 sessionStorage，按服务端已验证的会话隔离；刷新和切换回记录可恢复原请求 ID；成功才清理。失败提供“继续这次回答”。存储禁用不阻断当前页重试。不是云端保存，也不承诺关掉浏览器后恢复。

## 验证与边界

- 路由集成用受控模型响应，验证第一题、下一轮反馈、非法多题不落库、原文进入改写而请求不成为事实。原文引用与否定/新增数字安全回归、会话草稿隔离与存储失败回归。
- 隔离发布快照整库 190 套 / 1942 通过、4 跳过（随后补充 bullet 输出路由回归）；生产构建及类型检查通过。共享目录的 auth/admin 协作者改动未进入发布快照。
- UI 单次手动 Impeccable detect 无发现；不启自动钩子，不扫描或改历史视觉问题。
- 不把模型 mock 或构建通过当成真实模型/完整浏览器旅程验收。不宣称两份报告全部解决。

## 保留待办

- 原报告基础简历解析超时需要真实模型诊断；后台可恢复任务/持久回答、全站额度池口径和统一价签、Agent 安装说明仍待专项验证。

- 本轮不追加模型调用或自动付费重试；失败退回遵循既有 metered route 结算逻辑，不虚构免费重试政策。
