# 岗位时间线与辅导修复 · 2026-09-14

## 本轮实现

- 主界面收敛为岗位列表 + 当前阶段时间线 + 右侧辅导；移除重复今日返回路径。浏览阶段不写业务阶段。
- 时间线保留项目准备、简历、投递记录、面试、并行复盘、谈薪入口。当前就绪门读取质检状态与待确认修改，冻结显示真实版本 ID。准备阶段不强制 JD。
- 面试练习移到右栏；切换阶段保留已挂载的聊天和面试组件。逐题提示、点评后重新回答、真实整轮报告复用既有接口，失败不造分。
- Markdown 使用 react-markdown + GFM，不渲染原始 HTML 或远程图片。过滤导师口吻的快捷问题，包括旧记录按钮。
- 摘要/cache 是可降级输入，读取失败不阻断权威上下文、鉴权、生成与保存。新学习不再等待收费归档成功；旧会话保留。
- 学习笔记支持免费人工编辑/添加，owner + version 并发校验。归档不再追加原问题和系统 ID；手写笔记原样保留。非空笔记可在后续学习中召回，仍有预算与岗位隔离。
- 新增三种原生打印版式，保留中文文字层及浏览器分页。新窗口先同步打开避免异步弹窗拦截；版本读取经过 owner 校验。未确认/未质检的修改阻止旧稿误导出。保存需要用户在打印框选 PDF，并关闭页眉页脚。

## 已验证

- 56 套件 / 487 用例通过；TypeScript 通过；生产构建通过（后续小改另通过 tsc 和全量单测）。
- 浏览器实际打开默认时间线、准备状态和 PDF 预览。Chrome 打印预览显示一页中文 PDF，文字可被无障碍树读取；没有声称用户已下载。
- scripts/verify-learning-notes.mjs：实际登录路由创建临时会话，编辑、回读、过期编辑 409；只删除自身临时会话，不改旧数据，不调用模型。
- 最终单测仍为 56 套件 / 487 用例通过，tsc / diff-check 通过。
- 本地真实模型探针在 `/api/coach/agent/models` 得到 503「暂时无法读取模型配置」，未进入生成，不算聊天端到端通过。模型配置路径依赖 TokenPay 凭据解密；不清 Cookie、不解除授权、不导出生产密钥绕过。

## 边界 / 尚未完成的验收

- 本轮尚未部署正式域名，不能把 localhost 验收称为线上验收。
- 手机视口的原生浏览器控制未取得有效截图；多页长简历、三种版式完整导出尚未逐一验收。
- 投递跟踪目前复用已存动态，没有新增“上传回执→识别→核验”的自动闭环；不把冻结当成投递。
- 谈薪复用已有 Offer 管理入口；尚未把该流程完整移入右栏，也没有把 Offer 结束条件作为已实现完成状态。
- TokenDance llms.txt 列出的 Ark / MiniMax WebSocket 文档是文本转语音，不等于已提供 speech-to-speech 实时面试。未上线实时语音，也未在输入中自动评分。
- 新 PDF 入口使用本地原创三种简洁版式，未复制未经核对许可证的第三方模板；旧的无人调用图片式 PDF utility 尚未删除。
- 尚不能声称解决所有上游超时。 optional-memory 降级回归与真实模型链路结果应分别记录。

## 后续验收门

真实登录下：切换阶段时输入草稿不丢 → 修改笔记并开新辅导确认召回 → 单题回答保存/重答/完整总结 → 长简历导出且重新解析校验 → 手机视口 → 正式发布及线上回读。未过这些门不签收全部用户需求。
