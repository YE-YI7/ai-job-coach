# 个人 Agent 安装指令复制统计与套餐提案

## 范围与业务决定

本人要求恢复 Claude 的套餐分类并创建，同时想知道“复制 prompt 使用个人 agent 版本”是否有埋点。旧报价有冲突且被增长v2撤回；本人答复“那你思考一下吧”。本轮先提出三档通用积分包，未自行创建新付费商品或承诺人工服务，详`docs/product/2026-11-16-credit-package-proposal.md`。

实施范围仅网页复制入口与管理员统计。不改F6、B05、模型、工具、Memory、HR、扣费、钱包、已购权益、个人积分或旧作答。不运行安装脚本，不给本地MCP添加遥测，不新增模型调用或费用。

## 实际入口核对

正式首页是`app/page.tsx → HomeLanding → FirstLightHome`，只链接`/agent`；`HomeClient`仅由`/demo`使用。初次只检查HomeClient不足以证明正式入口已覆盖，实际浏览器首轮因找不到复制框失败，记录保留。修后增加契约测试锁定正式路由，并在正式`/agent`提供复制控件，旧演示页也复用同一指令与记录模块，用`agent_guide／demo`区分。

指令原文未改写、未增加追踪标识／用户ID／专属URL；仅抽成共享常量。页面明确只统计网页复制操作，本地材料不回传。现有安装命令与本地版运行方式不变。

## 可看见什么、不能看见什么

- `agent_install_prompt_copy_clicked`：点击复制按钮。
- `agent_install_prompt_copied`：Clipboard写入Promise成功后才记，失败不记成功。
- `agent_install_prompt_copy_failed`：Clipboard受限或API缺失；只记固定事件，不记异常原文。
- `agent_install_prompt_manual_copy`：指令框触发原生copy动作，单独计数，不冒充完整指令复制成功。

只传入口、固定版本等运营元数据，复用已有匿名标识、渠道归因与登录身份。无指令正文、简历／对话／联系方式／本地路径。没有数据库结构变更。

后台“数据→基础数据”新增“个人Agent·安装入口”：点击／成功的去重标识、成功／失败次数、手动复制动作。统计复用当前时间筛选、内部／QA排除和账号范围；选择仅注册用户等筛选时匿名事件会按既有范围排除。浏览器和账号标识不等于真人，登录前后或跨浏览器可能重复。

本地安装人数、真实使用人数仍为未采集，不返回0。复制≠安装≠使用，历史不能补算。已有`agent_resume_saved`等来自站点事件台账，不能证明所有本地Plugin活跃。
