# 首份软件工程工作的能力证据

## 核心知识

缺少正式经历时，简历的首要任务是让招聘者快速看懂候选人会什么、做过什么、证据在哪里。公开作品、GitHub 仓库和可运行项目可以补充证据，但提交次数、星标或技术名词不能替代项目质量。

## 简历证据顺序

1. 目标岗位要求对应的技术能力。
2. 能说明问题、个人责任、实现难点和结果的项目。
3. 可访问的代码、演示、文档或公开贡献。
4. 与岗位相关的学习经历和基础知识。

## Agent 检查

- 项目是否能在 20 秒内说明用途和个人贡献？
- 仓库是否可运行，README 是否解释安装、架构和限制？
- 简历是否把工具列表误写成能力证明？
- 投递结果是否被记录，用于继续调整目标岗位和材料？

持续投递用于降低单次结果波动，不代表无差别海投。每轮投递后仍要根据反馈修正证据表达。
