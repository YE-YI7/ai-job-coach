## 本批实现

### 首次回应与交接

首页明确提交才请求一次站点轻量模型；纯文字短理解加一个小行动，不运行简历编辑。未登录原话和回复仅在当前标签页 sessionStorage 暂存，24 小时失效，不进入 URL。登录跳转只携带 `entry=one_sentence&handoff=1`，服务端重新构造允许的返回地址。

同一句输入复用已存回应，编辑后的输入换新意图；迟到回应不得覆盖新草稿。登录后绑定首次接收账号，其他账号不自动读取；成功保存新目标后才清理该草稿。新目标不复用其他岗位的旧对话，旧目标与历史会话保留。页面刷新不会重复调用模型。

公开 API 默认关闭，候选开关 `LANDING_MENTOR_PREVIEW_ENABLED=1` 仅供验收。复用原服务端原子限频 RPC：每 IP 每日 3 次、全站每日 20 次、每意图 1 次；数据库/限额服务不可用时不调模型。只保存哈希计数，不更改短信限额，不加迁移。固定站点模型、350 输出上限、20 秒总时限、0 自动重试；不使用真人绑定的网关凭据。

模型、网络或预算不可用时，准确引用原话并邀请登录继续，不返回错误关键词模板、原始 provider 错误或内部 ID。前台首屏输入与示例卡不再等待入场动画。

### 整稿前的保护

“修改整份/重新修改整份”第一次点击只打开原生模态确认；默认焦点在“先不修改”，可 Escape 退出。明确说明整稿与独立质检、耗时可能几分钟及当前计费；不能可靠估算实扣时不捏造金额。只有确认后才调用原函数，双击保护不重复触发。“继续补充”仅跳到导师，不误当作收费整稿。

本批没有实现服务端运行取消，也没有把浏览器中止请求称作停止计费。
