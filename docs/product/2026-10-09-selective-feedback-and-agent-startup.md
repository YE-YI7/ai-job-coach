## 实现

- Agent 版本 0.8.7，新增 `yi_zhi_diagnose`。检查当前 MCP 通道、实际工具数量、Node/发布版本、知识库是否可读以及临时探针写入/删除；不读取简历、付款密钥或扣费。
- localhost 绑定失败：继续 stdio MCP，返回 `mcp-headless` 和真实错误码，保留岗位及成果存取，不生成不可用链接。
- 数据目录不可写：更新缓存写入失败不阻断初始化，诊断说明持久保存不可用。不能宣称材料已保存；持久化工具仍显式报错。
- `YI_ZHI_COCKPIT_DISABLED=1`：主动关闭本地界面，仍可使用无界面 MCP。
- 安装器在写入前校验 Node 18+；`YI_ZHI_SKILLS_ONLY=1 sh scripts/install-agent.sh codex` 明确只装方法，不复制 MCP 或声称接通。完整安装仍提示注册宿主后调用诊断。
