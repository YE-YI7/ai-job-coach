目标不是“收反馈”，而是确认用户能否在没有教学陪跑的情况下完成真实求职动作。

> 想邀请 2 位目标为产品、AI 或数字岗位的学生做一次 10 分钟内测。用户带一份已有材料独立完成，产品会整理岗位证据、简历和面试准备，并安排下一步。我们只记录是否完成和卡点，不使用材料做公开案例。入口：`https://www.ai-job-coach.xin/?utm_source=overseas-partner-pm`

所有渠道只发一次；24 小时后只追问已打开但未完成的人，不群发催促。

## 单人测试

1. 发对应来源链接，不先解释功能。
2. 观察能否在 10 分钟内完成首个价值动作。
3. 只问三题：哪里犹豫；哪一步不可信；如果明天继续，你希望它主动提醒什么。
4. 24 小时后查看 `npm run ops:funnel`，只对未激活用户追问一次卡点。
5. D3 问是否继续使用；完成一条闭环后询问付费或推荐意愿。

## 通过门槛

- 10 人中 8 人在 24 小时内完成首个价值动作。
- 5 人完成“导入材料 + 至少一次执行动作”。
- 3 人明确愿意继续付费或推荐。
- 未达到前不买量；优先修复最高频的第一个阻断点。

## 每日判定

```bash
npm run ops:env
npm run ops:funnel -- 14
```

报告按来源给出“进入作战盘 → 开始导入 → 材料完成 → 执行动作”的用户数和转化率，并直接指出当前首要阻断。没有真实用户时必须显示 0，不用测试账号补数。

埋点不保存 JD、简历、面试回答或聊天正文，只记录动作名称、来源、工作区类型和计数。
