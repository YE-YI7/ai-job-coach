# 基础档案与我的笔记视觉调整

范围：中间基础档案页面与右侧「我的笔记」抽屉。保留暖色系，不改其他岗位阶段业务逻辑、不改笔记存储或计费。

- 基础档案：标题与次要说明分层；已收录简历改为明确标注「查看 / 更新」的档案摘要，原文和替换入口在展开后呈现；方向编辑保留，辅导降为文字动作，找岗位是下一步主要按钮。不隐藏未上传状态的上传入口。
- 笔记：桌面目录/正文双区，最近30条本地搜索；目录展示标题与摘要；正文使用无矩形边框的编辑区，已有笔记默认排版阅读，可切回编辑。保存与未保存状态位于底部。手机目录横向浏览、正文纵向阅读。关闭/切换仍保护未保存草稿；失败保留草稿，继续使用原有乐观锁接口。
- 不加虚假笔记或统计。临时本地样例页用于检查切换、编辑、模拟保存与排版，验证后已删除，未部署，不接触真实账户。实际云端笔记保存未由本轮重新验收。
