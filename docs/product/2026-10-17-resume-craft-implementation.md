# 简历工作区细节实现 · 2026-10-17

## 范围

承接 [奇思喵想参考复查](2026-10-17-qisi-reference-reassessment.md)，把空间主次、编辑连续性、局部反馈和操作表面层级落实到既有简历工作区。保留左侧栏、上传原件、事实边界、保存队列与面试作答。未复制参考站的素材或品牌，未安装其网页中的脚本。

- 简历修改阶段的岗位上下文缩成一行；其他阶段不重建。导出保留主要动作，版式仍收在更多菜单。
- 文档衬底、纸张、就地编辑器、菜单和导师输入分别表达不同层级；不再用同样的边框把所有东西隔成同等重要的卡片。
- 标题和段落编辑就发生在对应区块，不再拉出覆盖整个工作区的大弹窗。删空先确认，删除可撤销；快捷键、可见焦点和触屏入口保留。
- 未保存段落在同工作区切换阶段、原件或回到修改稿时保留；按账号实例、机会与简历 revision 隔离。只放当前工作区内存，不存浏览器持久存储、不跨登录。刷新前仍需点段落保存并等云端回执。
- srcDoc 切版式会产生新 Document，portal 以实际 load receipt 重新定位，避免编辑器消失。iframe 仍仅 `allow-same-origin`，没有开放表单、脚本权限。
- 导师状态仅反映真实 task state，不制造百分比或假步骤；完成后让简历重新成为重点。

## 本地已验

真实 Chrome 的虚构 fixture 回放：`scripts/accept-resume-inline-ui.mjs`。明确 `synthetic: true, cloud: false`，不把它当正式站保存验收。

1. 标题原位保存，sandbox 不变。
2. 标题撤销与重做。
3. 删空确认，继续编辑保留草稿，取消保留原文。
4. 键盘空文本提交聚焦安全操作，Escape 返回输入，再取消回到当前编辑入口。
5. 未保存段落跨阶段和原件视图恢复。
6. 草稿跨实际版式切换并保存，回焦到当前 Document 的编辑控件。
7. 删除区块后撤销。
8. 390px 触屏选中、保存，无页面横向溢出。

最后八项完整回放通过。229 个测试套件、2297 项测试通过；5 套件/9 项 opt-in 跳过。TypeScript 与修改文件 ESLint 无新增错误，CockpitApp 两个历史 unused warning 不扩大修复。

## 设计检查边界

Impeccable hooks 保持关闭；手动 detector 已对改动目标运行一次。它仍提示历史问题和局部未文档化的色值/半径，不通过修改全站令牌来掩盖。独立 finish review 提出的草稿丢失、删除确认焦点和低对比焦点框已进入修复与定点回放；审查不等于用户审美批准。

DESIGN 与 sidecar 只同步实际撤掉的大弹窗、当前原位编辑器及触屏规则；未重写既有系统。现存 13px 岗位上下文、局部衬底和导师输入阴影与旧令牌记录存在漂移，只记录，不自动修历史规范。
