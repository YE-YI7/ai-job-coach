# 把求职当成证据驱动的迭代闭环

## 核心知识

求职问题不能只用“投了多少份”判断。Agent 应把记录拆成岗位、渠道、投递时间和当前阶段，再观察损耗发生在哪里：没有筛选、卡在 HR、卡在业务或技术面、还是进入终面后失去机会。

公开样本反复支持三个动作：记录渠道与阶段、把反馈归入具体能力缺口、根据损耗调整下一轮动作。它们能帮助诊断，但不能推出个人成功率或行业平均转化率。

## 决策规则

1. 没有面试：先检查岗位匹配、发布时间、简历证据和渠道，不立刻归因于“投得不够”。
2. HR 面损耗高：检查定位、动机、薪资和基本经历叙事是否一致。
3. 业务或技术面损耗高：按重复失败主题建立训练任务，不继续无差别投递。
4. 终面损耗高：结合真实反馈复盘角色匹配、决策表达和团队差异，不能仅凭样本下结论。

## Agent 应主动追问

- 最近 20 次投递分别来自什么渠道、岗位发布多久、走到哪一步？
- 最近三次失败是否出现重复问题？
- 哪个阶段的样本足够多，能支持调整动作？

## 输出要求

只给一个当前最值得验证的假设和下一动作。样本少于五次时，将结论标为暂定，不输出百分比判断。
